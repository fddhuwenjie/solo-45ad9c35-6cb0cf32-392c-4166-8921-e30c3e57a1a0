# 舞台快速换装编排

Flask（规则计算/排程）+ SQLite（演出与修订）+ 原生 JavaScript/SVG（场次时间轴、侧台平面图、服装层级卡联动）。

## 运行

```bash
python3 seed.py        # 首次：写入演示数据（含刻意安排的冲突）
python3 app.py         # 依赖 Flask（本环境装在 ../.pylibs，app.py 已自动加入 sys.path）
# 打开 http://127.0.0.1:5000
```

## 功能

- **录入**：演员出入口、角色造型（look↔服装清单）、穿脱依赖（层级顺序）、单件用时、
  服装师、换装位（坐标/容量）、服装车（停靠侧/容量）、场景间隔（场次起止）。
- **时间轴**：拖动任务块调整开始时间；点击选中；已锁节点（连排确认）不可拖动、重排不动。
- **重排规则**：动作先后（脱外→脱内→穿内→穿外→取道具）、人员并发（演员/服装师独占）、
  步行时间（平面图坐标/1.3m/s）、换装位容量、服装复用（copies 与脱下时刻）、
  清洁/维修状态（available_at 前不可用）。
- **冲突报告**：最早无法按时完成的动作（含预计/截止时刻）、服装师并发、换装位容量、
  缺件/复用冲突；并给出改动较少的替代排法（换装位/服装师/开始时间），可一键采用。
- **变更联动**：改场次时间或服装状态/服装车 → 仅关联任务置「待复核」，可逐个销记。
- **修订**：任意时刻存档快照，可恢复。
- **导出**：个人换装提示单（HTML 打印）、服装流转表（CSV）、带冲突标记的 SVG 时间线。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 全量状态 + 排程结果 |
| POST | `/api/reschedule` | 重排（已锁不动）并返回替代排法 |
| POST | `/api/tasks/<id>` | 拖动/改派/锁定/解锁 |
| POST | `/api/scenes/<id>`、`/api/items/<id>` | 变更并标记关联任务待复核 |
| POST | `/api/revisions`、`/api/revisions/<id>/restore` | 修订存档/恢复 |
| GET | `/export/cue/<actor_id>`、`/export/flow.csv`、`/export/timeline.svg` | 三类导出 |
